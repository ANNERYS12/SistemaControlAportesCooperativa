# Sistema de Control de Aportes Cooperativa

Proyecto desarrollado como parte de la asignatura. Implementa una API RESTful siguiendo el patrón controlador-contexto-modelo.

## Características:
- CRUD completo para la entidad **Socio**.
- Gestión de la entidad **Aporte** relacionada.
- Uso de **DTOs** para la transferencia de datos.
- Documentación automatizada con **Swagger**.

## Tecnologías:
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server

## Instrucciones de uso:
1. Configurar la cadena de conexión en `appsettings.json` (DefaultConnection).
2. Ejecutar el proyecto.
3. Acceder a `http://localhost:<puerto>/swagger` para interactuar con la API.
